# Experiment 2: Network Topology Creation using Scilab

## Objective
To create a hybrid network topology using Scilab by combining three basic topologies (Star, Ring, Bus) with minimum 25 nodes.

## Topology Details
- **Star Topology:** 1 central hub + 8 nodes (Nodes 1-9)
- **Ring Topology:** 10 nodes in a ring (Nodes 10-19)
- **Bus Topology:** 10 nodes on a bus (Nodes 20-29)
- **Total Nodes:** 29
- **Total Edges:** 30

## Features Implemented
- ✅ Hybrid topology with 29 nodes (exceeds 25 requirement)
- ✅ Color-coded nodes and edges (Blue: Star, Red: Ring, Green: Bus)
- ✅ Node numbering from 1 to 29
- ✅ Edge connections for all three topologies
- ✅ Hybrid connections between topologies
- ✅ Network statistics (node degree, total nodes, total edges)

## Network Statistics
| Parameter | Value |
|-----------|-------|
| Total Nodes | 29 |
| Total Edges | 30 |
| Node with Max Degree | Node 1 (Hub) with 8 connections |
