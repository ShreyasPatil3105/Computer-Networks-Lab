# Experiment 6: Wireshark - Checksum Calculations

## Objective
To validate checksums for UDP and TCP protocols using three methods:
- Method 1: Wireshark built-in validation
- Method 2: Manual calculation from packet headers
- Method 3: Scapy Python automation

- `ss3_method03_scapy_udp_output.png` - Scapy UDP checksum output
