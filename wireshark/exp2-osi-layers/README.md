# Experiment 2: Wireshark - OSI Layers

## Objective
To capture and analyze network packets to identify the different OSI layers using Wireshark.

## Protocols Analyzed
| Protocol | OSI Layer |
|----------|-----------|
| ARP | Layer 2 (Data Link) |
| ICMP | Layer 3 (Network) |
| TCP | Layer 4 (Transport) |
| DNS | Layer 7 (Application) |
| HTTP | Layer 7 (Application) |
